# E'memento — Food & Fun · Пловдив

Едностраничен уебсайт за ресторант **E'memento** в Пловдив (бул. „България“ 140).

## Характеристики
- **Hero секция** с три ястия, които обикалят около текста при скролване; текстът също се променя при скрол.
- Изцяло на **български език**.
- **Old money** луксозен стил — наситено червено и черно, бял серифен шрифт, дискретни анимации.
- Подбрани **положителни отзиви** от гости.
- **Интерактивна карта** (Google Maps) и форма за **резервации**.

## Структура
- `index.html` — съдържание и секции
- `styles.css` — визия и анимации
- `script.js` — скрол анимации, reveal ефекти, форма за резервация
- `assets/img/` — снимки на ястията

## Преглед
Отворете `index.html` в браузър или стартирайте локален сървър:

```bash
python3 -m http.server 8000
```

После: http://localhost:8000
